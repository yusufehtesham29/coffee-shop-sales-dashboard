🎯 Project Overview

An interactive Excel dashboard analyzing 149,117 transactions** from a coffee shop chain across 3 locations over 6 months (January - June 2023). Built to provide real-time business insights through interactive visualizations and dynamic filtering.

💰 Total Revenue Analyzed: $698,812.33

💼 Business Problem

Coffee shop management needed a tool to:
- 📊 Track sales performance across multiple locations
- ⏰ Identify peak hours for optimal staff scheduling
- 🏆 Understand product preferences and bestsellers
- 📅 Analyze weekend vs weekday sales patterns
- 📈 Monitor monthly revenue trends

🛠️ Technical Skills Demonstrated
- Data Cleaning & Transformation - Processed 149,117+ transaction records
- Excel Calculated Columns - Created 8 custom fields (Month, Day_Name, Hour, Total_Sales, etc.)
- Advanced Pivot Tables - Built 8 interconnected pivot tables
- Data Visualization - Designed 6 professional charts with consistent styling
- Interactive Dashboards - Implemented slicers for dynamic filtering
- Business Intelligence - Developed KPIs and actionable metrics

📈 Dashboard Features

4 Key Performance Indicators (KPIs):
| KPI | Description | Example Value |
| 💰 Total Revenue | Sum of all sales | $698,812.33 |
| 🛒 Total Transactions | Number of orders | 149,117 |
| 💳 Avg Transaction | Revenue per order | $4.69 |
| 📦 Product Categories | Unique categories | 10 |

6 Interactive Visualizations:

1. 📊 Sales by Product Category - Column chart revealing Coffee dominates at 39% of sales
2. 📍 Sales by Store Location - Bar chart comparing 3 locations (Astoria, Hell's Kitchen, Lower Manhattan)
3. 📈 Monthly Sales Trend - Line chart tracking 6-month performance trajectory
4. 📅 Sales by Day of Week - Column chart identifying Thursday & Friday as peak days
5. ⏰ Hourly Sales Pattern - Area chart showing 8-11 AM morning rush
6. 🏆 Top 10 Best-Selling Products - Bar chart highlighting Barista Espresso as #1

3 Interactive Filters (Slicers):
- Month Filter - Select Jan, Feb, Mar, Apr, May, or June
- 📍 Store Location Filter - Choose Astoria, Hell's Kitchen, or Lower Manhattan
- 🗓️ Day Type Filter - Filter by Weekday or Weekend

> All charts update instantly when filters are applied! 🎯

💡 Key Business Insights Discovered

| Insight | Finding | Business Impact |
| ☕ Top Category | Coffee = 39% of sales ($269K) | Focus inventory on coffee products |
| 🏆 Best Product | Barista Espresso leads all items | Feature in promotions |
| ⏰ Peak Hours | 8-11 AM generates highest revenue | Schedule more staff for morning rush |
| 📈 Busiest Days | Thursday ($9,106) & Friday ($8,648) | Plan promotions for Thu-Fri |
| 📍 Top Location | Lower Manhattan outperforms others | Replicate success at other locations |
| 💵 Avg Transaction | $4.69 per order | Opportunities for upselling |

🚀 How to Use the Dashboard

1. Download the Excel file from the link above
2. Open in Microsoft Excel (2016 or later recommended)
3. Enable editing if prompted by Excel
4. Go to the "Dashboard" sheet to view the main dashboard
5. Use the slicers (filters on the right) to:
   - Select specific months to analyze
   - Filter by store location
   - Compare weekday vs weekend performance
6. Watch all charts update automatically based on your selections!
7. Explore different combinations to discover insights

 Example Analysis:
- "What were Hell's Kitchen weekend sales in March?"
  - Select: Month = March, Location = Hell's Kitchen, Day Type = Weekend
  - View updated KPIs and charts instantly!
